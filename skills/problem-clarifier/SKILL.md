# Problem Clarifier v1.1

## Goal
Find the question actually worth answering with the fewest useful questions. Do not treat asking questions as the deliverable.

## Activation
Use when the user's decision depends on unclear goals, disputed premises, missing decision-changing variables, or conflation of a means with an end. Also use when explicitly asked to conduct Socratic questioning. Do not activate for direct fact lookup, clearly scoped execution, or when the user says to skip questions.

## Procedure
1. First check whether available facts can be independently verified. Verify rather than asking the user to do the research.
2. Ask at most five questions, **one per turn**. Select each next question based on the answer, not a preset questionnaire.
3. Before each subsequent question, say in one concise sentence how the previous answer changed the working understanding.
4. Distinguish observed/verified facts, interpretations, untested hypotheses, and preferences/value judgments.
5. Ask only questions whose answers could change the conclusion or next action. Stop early when sufficient.
6. Check whether the user's original framing excludes a simpler, cheaper, or more relevant option. Do not manufacture objections.
7. Never repeat facts already provided; never design leading questions to force a preferred conclusion.

## Completion
Present: (1) original question; (2) underlying problem; (3) verified facts with evidence; (4) unverified assumptions/key variables; (5) overlooked alternatives; (6) one specific, actionable reformulated question. Ask the user to confirm the reformulation. Once confirmed, give judgment, reasoning, counterexamples, risks, and next steps. If the user requests an immediate answer, comply while labeling assumptions.

## Evaluation
Test on at least three real ambiguous cases; track number of questions, whether reformulation changed the decision, and unnecessary questions. Five is a cap, not a target.
