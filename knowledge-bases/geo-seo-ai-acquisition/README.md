# GEO × SEO × AI 获客知识库

本目录是无相而生 GEO/SEO 研究与工具研发的独立工作区。暂不收录未经全文核验的论文结论。

## 目录规划

- `sources/` 原始论文、官方文档、行业报告的出处与版本信息
- `research/` 经全文审查的知识卡片、公式解读与技术关联
- `experiments/` 评估协议、问题集、原始回答、实验代码
- `cases/` 企业案例与证据核验
- `product/` 内部工具、商业交付与研发规格
- `learning/` 分主题课程、学习进度与错题复习
- `decisions/` 关键决策与变更依据

## 准入原则

1. 原始来源、研究方法、实验条件和版本核对后，才能形成正式知识条目。
2. 论文实验结果、平台官方声明、厂商营销案例、真实客户经营数据严格区分。
3. 技术术语和缩写首次出现须提供中文解释。
4. 每条工具需求应关联研究证据、商业价值、输入输出和验收标准。
5. 不上传客户隐私、API 密钥、访问令牌或未获授权的受限资料。

## 同步结构

本地 Codex/Git 仓库用于 PDF、代码和实验；Notion 用于知识阅读、教学和协作。原始资料未完成核验前，不输出正式教材。
